# PokeLinker

「ポケモン徹底攻略」の各ポケモンのページに「ポケモンバトルデータベース」へのリンクを生成し表示するChrome / Edge向けの拡張機能です。SV図鑑ページとチャンピオンズ図鑑ページに対応しています。

![README_1.png](https://github.com/suisui-swimmy/PokeLinker/blob/main/README_1.png?raw=true)

# 機能
- 「ポケモン徹底攻略」の各ポケモンのページに「ポケモンバトルデータベース」へのリンクを生成し表示します。
- SV図鑑では`PBDB(SV)`、チャンピオンズ図鑑では`PBDB(CH)`のリンクを表示します。
- 「ポケモンバトルデータベース」で表示する各ポケモンのページの、シングルバトル/ダブルバトルの切り替えとシーズン選択ができます。
- チャンピオンズ図鑑では、PBDBに掲載されたシーズン・レギュレーション・期間を配信データから読み込みます。

# 動作確認済みブラウザ
- Google Chrome (最新バージョン)
- Microsoft Edge (最新バージョン)
